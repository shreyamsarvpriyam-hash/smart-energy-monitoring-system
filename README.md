# Smart Energy Monitor

## Project Description
This project is a web-based smart energy monitoring system. It shows voltage, current, power, and a graph with high and low values.

## Features
- Live dashboard
- Power calculation
- High and low graph points
- High power warning
- Frontend and backend connection

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## How to Run
1. Open terminal in project folder
2. Run:
   npm install
   npm start
3. Open index.html in browser
